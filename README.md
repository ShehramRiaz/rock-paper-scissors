# 🎮 Rock Paper Scissors

A simple and interactive **Rock Paper Scissors** game built using **pure HTML, CSS, and JavaScript**. This project is focused on practicing DOM manipulation, event handling, game logic, and responsive web design without using any external libraries or frameworks.

## 🚀 Features

- Interactive gameplay
- Responsive design
- Clean and modern UI
- Pure HTML, CSS, and JavaScript
- Beginner-friendly code structure

> **Note:** This project is currently under development. More features and improvements will be added over time.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
